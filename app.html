The rules this room plays by

Where do the numbers come from?
Every value on this page is derived from one source: leaderboard.motion.game/api/leaderboard (official, unauthenticated) — the fields position, delta (4-hour rank change), isNew, plus asOf. A GitHub Actions cron snapshots all 79 creators every 4 hours onto the data branch; this page reads those snapshots. History starts the day the collector started — when a window has too few slots the field shows —, never a made-up number.
Why don't you just show Motion Score?
A creator's Motion Score is not public — it is built from X, Instagram, TikTok and YouTube engagement during the tournament — so nothing here claims to know it. Stars in the real game come from 14-day relative performance on a 1–8 scale; ours are estimated from rank and labelled as such.
Is the 32-star cap real?
It is the one Motion's own docs use as an example. The real cap is set per tournament, and tournaments also limit the rarity/boost mix, which this room does not model yet. Receipts grade rank movement, not score.
What happens when I lock a lineup?
The book is public. Locking files it — its X account, picks, thesis, pre-mortem — to data/receipts.json on the data branch through /api/receipts, and the server grades it against the snapshot on record, so a visitor cannot submit their own score. One receipt per handle per slot, so nobody can keep re-rolling a lineup until one hits.
